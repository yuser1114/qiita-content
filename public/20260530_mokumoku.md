# はじめに

今の現場でAIDD（AI駆動開発）が始まり、AIに指示を出して成果物を作成する機会が一段と増えました。
AIを活用していて気になったところは、プロンプトです。
プロンプトがいまいちなために、成果物の品質が下がり結果として手直しになっていることが良くあります。
そこで今回は、良いプロンプトを学んでいきたいと思います。

# 良いプロンプトとは

OpenAIが良いプロンプトの定義をしていたので、これをベースに学んでいこうと思います。

1. 明確で具体的なプロンプトを書く
   ChatGPTから最良の結果を得るには、常にタスクを明確にし、必要な背景情報を提供し、望ましいトーンや文体を設定してください。マーケティングトレンドの要約なのか、フォーマルなメールの下書きなのかなど、何を求めているのかを具体的に伝えましょう。明確で詳細なプロンプトは、ChatGPTがあなたの目的を素早く理解し、より適切で正確な回答を生成するのに役立ちます。

2. 依頼の適切な分量と優先順位を決める
   タスクが複雑な場合は、より良い結果を得るために、小さく焦点を絞ったプロンプトに分割してください。注目してほしい領域を指定したり、重要な点を強調したりします。必要であれば、要件により合うように複数の案を提示するようChatGPTに依頼してください。

3. 反復的に進める
   複雑なワークフローを複数のタスクに分け、個別のフォローアッププロンプトとして投げると、より良い結果につながることがあります。プロンプトは会話だと捉え、最初の回答を踏まえて依頼を改善しながら試行を続けてください。ChatGPTがより直感的に感じられるようになったら、完璧な言い回しに頼るよりも、自然で目的志向の言葉により頼れるようになります。目的に集中し、そこへ到達する手助けをAIに任せましょう。

※OpenAIから抜粋

# 明確で具体的なプロンプトを書く

これは意識はしているけど、タスクによって詳細があっさりしていたりすることがあります。
普段のタスクで、サービスの性質や言葉の意味をなんとなくで理解しているために、
具体的に指示できていない一つの要因だと思います。

# 依頼の適切な分量と優先順位を決める

結構やってしまうのが、「この機能を作りたいから〇〇と〇〇を作ってほしい」や「〇〇して、〇〇をつくってほしい。ついでに〇〇を消してほしい」のような複数のタスクを同時に依頼するケース。
一回の指示でできてほしい願望があるから簡単なタスクだとやりがち。

# 反復的に進める

これは結果的にそうなっている気がします。
一回目の指示でうまくいかなかったから気づいた足りない情報を出したり、不要な情報を排除してみたりすることはよくある気がします。

なんとなく理解はできるものの具体的にどうすればいいかわからないので普段お世話になっている
ChatGPTさんに聞いてみよう！

# ChatGPTさんに聞いた普段の指示に対する改善案がこちら

- 「最終的に何を達成したいか」が足りないことがある
- 「今回一番知りたいこと」の優先順位が足りないことがある
- 「回答してほしい形式」の指定が足りないことがある
- 「前提条件」の粒度が少し足りないことがある
- 「対象外にしたいこと」が足りないことがある
- 「判断基準」を求める指定がもっとあると良い
- 「自分の仮説」をもう少し明確に書くと良い
- 「どのレベルの回答が欲しいか」を毎回少しだけ足すと良い
- 「入力例・期待出力」が足りないことがある
- 「一気に完成形まで求める」より「段階分け」の指定があると良い

そ、そんなに言わなくても…
それぞれに対して過去の具体例をちゃんと出してくるから沁みるぜえ…

# まとめ

以下に気を付けて指示を出すよう心がけようと思います！

- 指示を出す前に自分自身がはっきりと理解できていない物事を把握してからプロンプトを考えるようにする
- 目的を達成するために、何をしてもらう必要があるのか明確にする
  　（やろうとしている目的に対してどういったことが必要かはじめに相談するのもあり）
- タスクを分割する
- 1回目で綺麗に指示を出すのではなく、段階的に指示を整えていくことを意識する
- 前提条件(対象外にするものとか)を整理して伝える
