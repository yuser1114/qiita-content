## CloudWatchとCloudTrailとConfig

似たような機能なので、問題をよく読んでも間違える。

- CloudWatch
  AWSリソースおよびAWS上でホストされているアプリケーションのモニタリングサービスです。
  EC2インスタンスのメトリクス監視内容をダッシュボードに表示することで、CPU使用率などを追跡できます。

- CloudTrail
  ユーザーのアクセスログとAPIログの取得および監視を行うサービス

- Config
  「AWSリソースの『構成（設定値）』を記録し、それが『ルール（正しい状態）』に沿っているかを判定するツール」です。
  AWSリソースの構成設定を評価、監査、及び審査するためのサービス

### 覚え方

CloudWatch：状態を見る
CloudTrail：操作の足跡を見る
Config：設定の変化を見る

## EC2

似たようなサービスが多いのと、EC2に関するものが多いので混合しやすい。

- EC2(Amazon Elastic Compute Cloud)
  オンプレミスでホストされる仮想サーバーに相当するAWSサービス
  AZに設置されるサービス
  ユーザーが基盤となる仮想インフラストラクチャのパッチ管理などの管理権限を保持できるサービス
  コンピューティングエンジンとして使用できるサービス
  ボリュームデータのバックアップ機能：スナップショット

- EBS(Elastic Block Store)
  EC2インスタンスと連携して使用できる高性能かつ高可用性のブロックストレージです。
  インターネットから直接アクセスができない完全な内部サーバー向けのストレージとしてセキュリティを強化することが可能です。
  しかし、複数のEC2インスタンスから EBS（汎用）ボリュームを共有できません。ただし、EBSのプロビジョンドIOPSタイプに限り、複数のEC2インスタンスからのアクセスが可能です。
  Amazon EBSはスナップショットを生成することにより、ボリュームデータをAmazon S3にバックアップして、データの損失を防ぐことができます。
  データを保存するためにEC2インスタンスにデフォルトでネットワーク経由でアタッチされるストレージ
  EC2インスタンスで処理される常に変化するデータを保存するのに最適なストレージ
- EFS(Elastic File System)
  EC2インスタンスからアクセスされる共有ファイルシステムのサービス
  NASと同様の機能を持つファイルストレージサービス
- ECS(Elastic Container Service)
  EC2インスタンスクラスター上でコンテナ化されたアプリケーションを実行するサービス
  Dockerコンテナをサポートし、優れた拡張性とパフォーマンスを提供するコンテナオーケストレーションサービス
- EKS(Elastic Kubernetes Service)
  AWS上で Kubernetes を使いやすくするマネージドサービス
- インスタンスストア
  EC2インスタンスの一時的なデータを保存する際に利用するストレージ
- AWS Fargate
  AWS Elastic Container Service（ECS）とAWS Elastic Kubernetes Service（EKS）で動作する、ホストマシンを意識せずにコンテナを実行する環境
  サーバーレスコンピューティング

### 覚え方

EC2：仮想サーバー本体
EBS：EC2につけるディスク
EFS：共有フォルダ
ECS：AWSのコンテナ管理
EKS：Kubernetes管理
ECR：コンテナイメージ置き場
Fargate：サーバー管理なしでコンテナ実行

## インスタンス購入方式

問題文から読み取るのに意外と手こずっていた。

- オンデマンドインスタンス
  一週間の期間限定でEC2インスタンスを利用する
- リザーブドインスタンス
  1年または3年の利用期間を事前に予約し、割引を受けるインスタンスの購入方法
- スポットインスタンス
  最も安価な価格で提供される未使用のEC2インスタンスです。AWSが管理する未使用のインスタンスを一時的にユーザーに貸し出すのがスポットインスタンスです。
  一時的な利用であるため、途中で停止するリスクはありますが、非常に低コストで利用可能です。
- スケジュールドリザーブドインスタンス
  週一回金曜日や、１０時から１７時といった定期的な利用時間にかぎってインスタンスを利用する場合の購入方式ですが、現在は利用が停止されています。

### 覚え方

オンデマンドインスタンス= 今すぐ使う・縛りなし。
リザーブドインスタンス（RI）= 長く使う前提で割引を取る。
スポットインスタンス= 空いている席を安く借りる。
スケジュールドリザーブドインスタンス= 定期的な時間帯だけ予約する昔の仕組み。

## AWS Systems Manager

一つのワードで色々な機能を内包しているのでわかりにくい。

EC2 などのサーバーやノードをまとめて管理・運用しやすくするサービスです。

- Session Manager
  EC2 などに安全に接続するための機能です。インバウンドポートを開けず、踏み台ホストや SSH キー管理なしで接続できるのが大きな特徴です。
- Parameter Store
  設定値や秘密情報を保存する場所です。パスワード、DB接続文字列、AMI ID などを安全に階層構造で保存できます。
- Run Command
  複数のマネージドノードに対して、リモートでコマンド実行や設定変更を行う機能です。大規模な一括変更にも使えます。
- Patch Manager
  OS や一部アプリケーションへのパッチ適用を自動化する機能です。スキャンだけも、自動インストールもできます。

### 覚え方

Systems Manager = サーバー管理の総合窓口
Session Manager = 安全ログイン
Parameter Store = 設定値・秘密情報の保管
Run Command = リモート実行
Patch Manager = パッチ管理
